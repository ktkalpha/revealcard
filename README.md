# Revealcard

한 서버의 공개 카드 셋은 로그인 없이 학습할 수 있습니다. 비공개 셋은 로그인한 소유자에게만 보이며, 공개 셋도 소유자만 수정할 수 있습니다. 학습 표시와 작성 중인 초안은 각 브라우저에 따로 보관됩니다.

## 실행

Node.js 20 이상이 필요합니다.

```sh
npm install
npm run build
npm start
```

기본 주소는 `http://localhost:3001`입니다. 개발 중에는 별도 터미널에서 `npm run dev:server`와 `npm run dev`를 실행합니다. Vite는 `/api`를 로컬 서버로 전달합니다.

카드 셋과 계정은 기본적으로 `.data/revealcard.json`에 저장됩니다. `DATA_FILE`로 경로, `PORT`로 포트를 바꿀 수 있습니다. **영속 디스크가 있는 단일 Node 프로세스**로 운영하고 데이터 파일을 정기적으로 백업하세요. 여러 프로세스 또는 서버 인스턴스가 같은 파일을 공유하는 구성은 지원하지 않습니다. GitHub Pages처럼 정적 파일만 제공하는 호스팅에서는 공유 기능이 작동하지 않습니다.

외부에 공개할 때는 HTTPS 역방향 프록시 뒤에서 실행하고 `COOKIE_SECURE=1`을 설정하세요. 계정 비밀번호는 해시로 저장되며 로그인 세션은 임의 토큰의 SHA-256 해시와 만료 시각을 데이터 파일에 저장하므로 서버 재시작 후에도 유지됩니다. 로그인·회원가입의 **로그인 유지** 옵션은 기본 선택이며 최대 30일 동안 유지합니다. 해제하면 브라우저 세션 쿠키를 사용하고 최대 24시간 동안 유효합니다. 로그아웃하면 서버에서 해당 세션을 폐기하며, 같은 브라우저에서 다시 로그인하면 이전 세션도 교체됩니다. 이 서버를 이용하는 누구나 공개 셋의 카드 내용을 볼 수 있으므로 민감한 내용은 비공개로 유지하세요.

기존 브라우저 카드가 있다면 로그인 후 **내 카드 → 브라우저 카드 가져오기**에서 한 번 가져올 수 있습니다. 모든 셋은 비공개로 생성되고 원래 브라우저 데이터는 삭제되지 않습니다. 계정별로 한 번만 가져올 수 있으니 다른 기기의 카드는 파일 내보내기·불러오기를 이용하세요.

카드 셋 공유 파일의 구조는 [CARD_SET_FORMAT.md](CARD_SET_FORMAT.md)를 참고하세요.

## 사진 추가 · 자르기

카드 편집기와 본문 편집기의 **사진 추가**로 PNG/JPG/WebP 사진(최대 5MB)을 올려 본문에 `![설명](...)`으로 넣을 수 있습니다. 파일 선택, 끌어다 놓기, 붙여넣기(Ctrl+V)를 지원하며 업로드는 로그인한 사용자만 할 수 있습니다. 올리기 전에 **박스 자르기**(자유·1:1·4:3·16:9 비율)나 **자유 자르기**(테두리를 따라 그리면 바깥쪽이 투명해집니다)로 필요한 부분만 남길 수 있고, 여러 번 이어서 자를 수 있습니다. **형광펜**으로 사진 위의 중요한 부분을 노랑·분홍·초록·파랑으로 칠할 수도 있습니다(굵기 선택, 마지막 획 취소). 칠한 표시는 사진에 합쳐져 저장되며 자르기와 함께 쓸 수 있습니다. 긴 변은 1600px로 줄여 저장합니다.

사진은 `DATA_FILE`과 같은 디렉터리의 `images/`에 추측할 수 없는 이름으로 저장되며, 링크를 아는 사람은 로그인 없이 볼 수 있어 공개 셋에서도 표시됩니다. 비공개 셋의 사진도 링크가 알려지면 열람할 수 있으니 민감한 사진은 올리지 마세요. 이 디렉터리도 백업하세요. 한 번 본 사진은 오프라인에서도 표시되도록 브라우저에 캐시합니다.

## 오프라인 사용

온라인에서 **내 카드 → 오프라인 저장**을 눌러 필요한 카드 셋을 이 기기에 저장하세요. 이후 같은 브라우저에서 서버에 연결되지 않으면 저장한 셋으로 학습할 수 있습니다. 저장본은 자동 동기화되지 않으므로 카드가 바뀌면 **저장본 업데이트**를 누르세요. 오프라인에서는 카드 및 셋 편집, 로그인, 서버 저장이 불가능하며 학습 표시는 이 브라우저에 보관됩니다. 공유 기기에서는 비공개 카드 셋을 오프라인 저장하지 마세요.

**파일 다운로드**는 별도의 `.revealcard.json` 파일을 만들며, 다른 기기에서 온라인 상태로 불러올 수 있습니다. 파일만 다운로드해도 이 앱의 오프라인 목록에 저장되지는 않습니다.

PWA 설치와 서비스 워커는 빌드된 앱을 `localhost` 또는 HTTPS로 제공할 때 사용할 수 있습니다. 처음에는 온라인에서 앱을 한 번 열어야 앱 화면이 캐시됩니다. 개발용 Vite 서버에서는 서비스 워커를 등록하지 않으므로 오프라인 동작은 `npm run build` 후 `npm start`에서 확인하세요.

## 실험실 · 커스텀 펫

로그인한 사용자만 사용할 수 있습니다. **실험실 → 이미지 선택**으로 원본을 올리면 웹사이트 서버에 설치된 Codex CLI가 자동으로 표정 4가지를 생성합니다. 사용자가 프롬프트를 복사하거나 완성 이미지를 다시 올릴 필요가 없습니다. 서버의 ChatGPT 로그인과 내장 이미지 생성 도구를 사용하며 별도 API 키는 필요하지 않습니다. 사용자 컴퓨터를 켜 둘 필요가 없습니다.

펫은 학습 화면에 계속 표시됩니다. 마우스나 터치로 캐릭터를 드래그해 원하는 위치로 옮길 수 있습니다. 놓은 위치는 계정에 저장되며, 화면 크기가 바뀌어도 화면 안에 유지됩니다. 캐릭터에 키보드 초점을 맞추면 방향키로도 이동할 수 있습니다. 이름·크기·좌우 위치를 바꿀 수 있으며, 기억한 카드는 웃음, 다시 볼 카드는 응원, 학습 완료는 축하 표정으로 반응합니다. 생성 중에는 원본 이미지를 표시합니다. 원본과 표정은 서버에 계정별로 저장하며 해당 계정으로 로그인해야 읽을 수 있습니다. PNG/JPG/WebP, 최대 8MB를 지원합니다.

서버는 `DATA_FILE`과 같은 디렉터리의 `pets/`에 설정·작업 큐·이미지를 저장합니다. 이 디렉터리도 백업하세요. 생성 작업기는 같은 서버에서 큐를 직접 읽습니다. Codex 로그인 정보는 서버에만 남습니다.

### 서버 Codex 작업기

서버 사용자 `kobyte01`의 Codex는 `/home/kobyte01/.local/bin/codex`에 설치되어 있습니다. `codex login status`가 ChatGPT 로그인 상태인지 확인하세요. 한 번 실행하려면:

```sh
PET_DATA_DIR=/home/kobyte01/.local/share/revealcard/pets node worker/pet-worker.mjs --once
```

`PET_DATA_DIR`, `PET_CODEX_BIN`, `PET_WORK_DIR`로 저장 디렉터리·실행 파일·작업 디렉터리를 바꿀 수 있습니다. `--once`는 대기 작업 한 개만 처리하고 종료합니다. 기본 저장 디렉터리는 `~/.local/share/revealcard/pets`, Codex 경로는 `~/.local/bin/codex`, 작업 디렉터리는 저장 디렉터리 안의 `worker-jobs/`입니다.

서버 자동 실행 설치:

```sh
mkdir -p ~/.config/systemd/user
cp worker/revealcard-pet-worker.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now revealcard-pet-worker.service
```

서비스 파일의 프로젝트·Codex·저장 경로는 현재 서버 설정에 맞춰져 있습니다. 다른 서버에서는 경로를 수정하세요. 작업기는 5초마다 큐를 확인하며 투명 2×2 PNG를 자동 적용합니다. 작업 중단 시 20분 후 재시도하며 최대 2회 시도합니다. 생성 실패는 실험실에서 다시 시도할 수 있습니다.

상태와 로그 확인:

```sh
systemctl --user status revealcard-pet-worker.service
journalctl --user -u revealcard-pet-worker.service -n 30
```
